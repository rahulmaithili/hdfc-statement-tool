# HDFC Bank Statement Analyzer 📊

A premium, client-side financial dashboard to analyze and visualize HDFC Bank statements safely and securely offline.

## 🔗 Live Application Link
🚀 **[Click here to open the Analyzer Online](https://rahulmaithili.github.io/hdfc-statement-tool/)**

---

## ✨ Features

*   **100% Client-Side & Secure:** Statement PDFs are parsed entirely inside your browser using `pdf.js`. No bank details, transactions, or personal data ever leave your computer or get uploaded to any server.
*   **Stripe-Inspired Premium UI:** A beautiful, responsive workspace with complete Dark Mode & Light Mode support.
*   **Chevron Filter Bar (Quick Action):** Filter your statement transactions instantly via visual pipeline steps:
    `ALL TRANSACTIONS ➔ UPI PAYMENTS ➔ BANK TRANSFERS ➔ SHIV SHAKTI (HP GAS) ➔ BANK CHARGES`
*   **Dedicated HP Gas Categorization:** Automatically maps transactions matching `SHIV SHAKTI` or `HPGAS` to a distinct `"Shiv Shakti (HP Gas)"` category.
*   **Interactive Insights Chart:** Interactive category breakdown donut chart powered by `ApexCharts`.
*   **Excel Export Tool:** Export all transactions, currently filtered records, or custom checkbox-selected items directly to Excel-friendly CSV spreadsheets.
*   **Details Inspector Modal:** Tap any transaction row to open a full metadata inspect card.
*   **Optimized Print Format:** Tap "Print" to cleanly export dashboard summaries or active tables as PDF.
*   **Mobile-App Experience:** Features a mobile-responsive card layout conversion for tables, collapsing sidebar panel, and quick access bottom navigation bar.
